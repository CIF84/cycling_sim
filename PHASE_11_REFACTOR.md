# Phase 11 Refactor — Progressive Disclosure

## Theme

Make Bike Science Pro feel simpler while preserving its analytical depth.

Phase 11 is not about adding more calculations. It is about changing how information is revealed.

Core principle:

> Reveal complexity progressively.

The app should show the user what matters first, then expose detail only when it is useful.

---

## Problem

The app now has strong functionality:

- GPX route support
- route intelligence
- ride briefing
- recommendations
- performance analysis
- opportunity ranking
- upgrade advisor
- current analysis / narrative layer

But the UI shows too much at once.

This creates cognitive overload.

Users can see the app is powerful, but they may not immediately know where to look or what to do next.

---

## Goal

Reduce visible complexity without reducing capability.

The app should feel like:

```text
Question
→ Summary
→ Answer
→ Evidence
→ Details
