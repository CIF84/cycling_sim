# Groupset presets · checked 16 October 2026

The catalog in `src/model/gearing.ts` contains **25 curated example configurations** from Shimano and SRAM's current road/gravel families. These are convenient simulation starting points, not a claim that a groupset has one standard gearing combination. Complete bikes often use different cranksets, chainring sizes or cassettes. Match the actual bike using the editable tooth counts.

Only official manufacturer product/service pages, technical manuals, exploded diagrams and compatibility tables were used. No retailer, review site or third-party cassette database supplies catalog values. Checked date: **2026-10-16**. Specifications are versioned data, not fetched at runtime. Product availability can vary by country.

## Included configurations

Each row sets **both** chainrings and the full cassette cog list. The rear derailleur identifies the manufacturer configuration used to check the cassette range; the app does not simulate shifting electronics or certify that components fit a user's frame, freehub or existing drivetrain.

## Generation and compatibility decisions

- **Shimano road:** R9200 DURA-ACE and R8100 ULTEGRA use 12 speeds. The 105 example covers mechanical R7100 and Di2 R7150 using **CS-R7101**, which supports both; the older CS-R7100 cassette is Di2-only. Tiagra is explicitly **R4000, 2×11**, not the preceding 4700 2×10. SORA R3000 and CLARIS R2000 remain listed in Shimano's current road catalog. See the [current road crankset index](https://productinfo.shimano.com/en/spec/road-crankset), [crank specifications](https://productinfo.shimano.com/pdfs/product/archive/2025-2026_Specifications_v035_en.pdf), [Tiagra R4000 crank](https://bike.shimano.com/no-NO/products/components/pdp.P-FC-R4000.html), and [road/gravel cassette compatibility table C-254](https://productinfo.shimano.com/en/compatibility/C-254).
- **GRX:** RX825 Di2 and mechanical RX820 doubles use an RX820 48/31 crank; the RX610 double is 46/30. Mechanical RX820 1×12 has separate 10–45 (RX822-GS) and 10–51 (RX822-SGS) examples. RX827 and RX717 Di2 are 1×12 with 10–51. RX610 1×12 uses the RX822-SGS derailleur, not an invented RX610 rear derailleur; RX717's example uses the existing 40T RX610 crank. The RX400 2×10 example uses the RX600-10 crank and HG500 11–34. For the 1×12 examples, XT CS-M8100 is one documented compatible cassette, not a claim that all GRX builds include XT. Sources: [GRX configurations](https://bike.shimano.com/en-NA/stories/article/shimano-grx-personalities1.html), [RX610 crank](https://bike.shimano.com/products/components/pdp.P-FC-RX610-1.html), [RX825](https://bike.shimano.com/es-ES/stories/article/shimano-grx-di2-12-speed.html), [RX827](https://bike.shimano.com/en-UK/stories/article/shimano-gravel-goes-wireless.html), [RX717](https://bike.shimano.com/stories/article/shimano-expands-grx-family-with-rx717-components.html), [GRX 10/11-speed component chart](https://bike.shimano.com/content/dam/productsite/shimano-northamerica/pdf/GRX%20DOC%20CONSUMER.pdf) and C-254 above.
- **CUES drop bar:** the U6040 2×11 example uses the HG CS-RS400 11–36 cassette and 46/32 crank. The U6000 1×11 example uses LINKGLIDE CS-LG400 11–50 and the 40T U6030 crank. These are distinct systems; the presets do not mix HG and LINKGLIDE cassette indexing. See [Shimano's drop-bar CUES guide](https://bike.shimano.com/en-UK/stories/article/shimano-cues-for-drop-bar.html) and [2026–27 specifications, FC-U6040-2](https://productinfo.shimano.com/pdfs/product/thisyear/2026-2027_Specifications_v023_en.pdf).
- **SRAM road:** RED/Force/Rival AXS E1 are 2×12 here, with manufacturer-listed matched 13-tooth front differences. The E1 road derailleurs support the selected 33/36T cassettes. Rival retains the CS-XG-1250-D1 cassette; a current groupset need not have E1 on every part. See SRAM's [AXS compatibility map](https://www.sram.com/globalassets/document-hierarchy/compatibility-map/road/axs-components-compatibility-map.pdf), plus the linked crank and cassette specifications in the table.
- **SRAM gravel:** RED/Force/Rival XPLR E1 are **1×13, 10–46**, whereas Apex XPLR mechanical/AXS D1 examples are **1×12, 11–44**. They must not be conflated with older 12-speed RED/Force/Rival XPLR. The 13-speed Full Mount systems require a suitable UDH frame; this is not checked by the simulator. See SRAM's [XPLR setup guide](https://www.sram.com/en/learn/xplr-axs-welcome-guide/tech-tips-and-tuning), [AXS compatibility map](https://www.sram.com/globalassets/document-hierarchy/compatibility-map/road/axs-components-compatibility-map.pdf), and [Apex mechanical specifications](https://www.sram.com/en/service/models/rd-apx-1-d1).

The first catalog deliberately does not enumerate every chainring/cassette combination, earlier generation, triple crank, road 1× race setup, or MTB/Eagle mixed drivetrain. CUES has other speed-count options beyond these two examples. ESSA's manufacturer overview positions it for casual MTB/fitness/city use, so it is outside this initial road/gravel selection. Manual gearing remains available for all of these; the app makes no availability or equipment-purchase recommendation.

## Model and user-interface behavior

- Default now: Shimano 105 R7100, **50/34 with 12-speed 11–34**. Previous beta: 50/34 with 11-speed 11–32. This intentionally changes cadence/lowest-ratio insights; moving time, speed, work and the four comparisons do not change.
- Applying a preset copies both arrays in one input update. No brand-dependent changes to mass, power, CdA, rolling resistance, drivetrain efficiency, wheel circumference or preferred cadence.
- Editing either tooth list selects Custom. Merely focusing/leaving a field, or reordering identical tooth counts, keeps the selected preset. Invalid custom lists retain the existing model validation; selecting a preset or resetting recovers valid gearing.
- Choosing Custom preserves the existing counts. Reset restores the default 105 setup. Switching English/Czech preserves the selected preset and calculations. Only language is stored across refreshes.
- Each selection shows its exact front teeth, cassette range, front/rear counts and expandable official references. The downloaded briefing records the actual tooth lists, including custom edits.
- Gear selection still finds the closest virtual cadence. It does not penalize cross-chaining or restrict sustainable power/speed when cadence is impractical. Manufacturer references document the curated examples; manual edits are not a drivetrain compatibility checker.

## Maintenance and verification

For a new preset, verify a current manufacturer listing, matched chainring combination, **every** cassette cog and the intended derailleur configuration. Add the part IDs and official URLs, review all entries before advancing the shared checked date, and document any generation change. Do not infer a list from its largest/smallest sprocket or copy a retailer's claimed configuration.

Catalog checks cover every preset's valid, unique, ordered counts and official source domains. Regression cases distinguish 11-speed Tiagra, 12-speed road, 13-speed XPLR, Apex 12-speed, and the GRX GS/SGS cassette lists. An independent cadence calculation verifies the gear-ratio effect; simulation checks assert unchanged time, work and comparisons. Desktop/mobile browser checks exercise preset changes, both custom fields, validation recovery, reset, translation, source links, download, accessibility and 320 px overflow.
